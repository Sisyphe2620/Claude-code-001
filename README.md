# Pinawa Float Race

一款手机横屏的 3D 漂流竞速网页游戏。六个漂流圈顺着峡谷河道往下冲：躲开礁石，吃气泡水罐攒技能，用鳄龟和豪华水枪干扰对手，第一个冲过终点的拿冠军。

- **在线游玩**：https://sisyphe2620.github.io/Claude-code-001/
- **代码仓库**：https://github.com/Sisyphe2620/Claude-code-001
- **技术**：单个 HTML 文件，用 Three.js r128 做 3D 渲染，用 Web Audio 现场合成音乐和音效，不需要编译或安装。

### 本地运行

浏览器会限制直接双击打开的本地文件，所以要用本地服务器打开：

```bash
cd Claude-code-001
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

需要联网：Three.js 从 cdnjs 加载（失败时自动改用 jsDelivr），标题字体来自 Google Fonts。

### 部署

仓库已开通 GitHub Pages（分支 `claude/video-upload-question-h4q19k`，根目录 `/`）。推送到这个分支后，网站 1～2 分钟内自动更新。

## 2. 玩法

### 目标

从「Pinawa Start」出发，顺河漂到「Pinawa FINISH」。一局大约 1 分半钟，六名选手中你对五个电脑对手。

### 操作

| 动作 | 手机（横屏） | 电脑 |
|---|---|---|
| 划桨前进 | 自动 | W / ↑ |
| 转向 | 左下角 ◀ ▶ | A D / ← → |
| 倒划减速 | 左侧「倒划」 | S / ↓ |
| 蓄力跳跃 | 右侧「蓄力跳跃」长按，圈满后松手 | 长按空格，蓄满后松开 |
| 扔鳄龟 | 右下角「扔鳄龟」 | Q |
| 豪华水枪 | 右下角「豪华水枪」 | E |

### 河道元素

| 元素 | 作用 |
|---|---|
| 礁石 | 撞上会减速、被弹开。生成时保证缝隙比漂流圈宽，不会卡死 |
| 白色急流段 | 水流更快、礁石更多，河道变窄 |
| 绿色箭头加速带 | 压上去自动冲刺约 0.9 秒 |
| 气泡水罐（粉、蓝、绿、橙，会发光） | 吃 1 罐加 1 分，最多存 3 分；被吃后 7 秒在原地重新出现 |

### 技能（集满 3 罐气泡水后可用，用一次扣 3 罐）

目标都是 **70 米内离你最近的对手**。附近没人时不会扣罐子。

- **扔鳄龟**：鳄龟沿抛物线飞过去，趴在对方漂流圈上。对方被吓得乱晃、难以操控，最高速度降到约 55%，持续约 2.6 秒。
- **豪华水枪**：手边吹出泡泡，「啵」一声变出加特林转管水枪，泵两下后喷出半透明水柱。对方被喷翻船，约 2.6 秒完全不能操作，只能被水流冲着走。你自己放水枪时会触发慢动作特写镜头，画面上下有电影黑边。

电脑对手也会吃罐子、放这两个技能。

### 蓄力跳跃

- 长按约 0.8 秒蓄满，松手跳起约 4.6 米，滞空约 1 秒。没蓄满就松手不会跳。
- 空中不会撞礁石和其他选手，也吃不到罐子。
- 落水时溅起大水花和一圈波纹，7 米内的对手会被往外冲开并晃一下。
- 落水后有 1 秒冷却。目前只有玩家能用，电脑对手不会跳。

### 其他机制

- **开局缓冲**：「出发」后前 10 秒，水流从 40% 渐渐加到正常，最高速度从 85% 渐渐加到正常。
- **自动脱困**：比赛中连续 2 秒、每秒前进不到 1.5 米，就会自动跳到下游约 9 米处的空位。倒划时不触发。
- **追赶平衡**：电脑对手离你太远时会稍微放慢，落后时会稍微加快，让比赛保持接近。

## 3. 自定义选手

开始菜单里有 6 位选手：你、阿浪、小鱼、石头、飞燕、老船长。

- 点任意头像可以从相册选照片、拖动和缩放裁剪、改名字（最多 6 个字）。编辑框底部的「上一位 / 下一位」能在 6 人之间切换。
- 「一次选多张照片」可以一次选最多 6 张，按顺序分给各位选手。
- 头像做成带白边的圆形大头贴，用在：比赛中人物的头、顶部进度条、开始菜单、结果排行榜。
- 照片和名字只存在当前浏览器的 localStorage 里（键名 `river-tube-avatars-v1`），**不会上传到任何地方**。换设备或清除浏览器数据后要重新设置；朋友打开链接看到的是默认头像。

## 4. 界面

- **加载页**：全屏的 Pinawa Float Race 主视觉图，底部一条橙色进度条和百分比。3D 引擎下载失败时会显示原因和「重新加载」按钮。
- **开始菜单**：标题、玩法说明、选手头像栏、音乐和音效开关、「开始比赛」。
- **比赛画面**：
  - 左上：名次、速度。
  - 顶部中间：所有选手的头像进度条。
  - 右上：静音按钮、计时、小地图（白色段是急流）。
  - 底部中间：气泡水 3 格。
  - 手机按键：左边方向键和倒划；右边蓄力跳跃和两个技能按钮。
- **结果页**：第几名、带头像的排行榜（你那一行橙色高亮）、「再来一局」、右上角「退出」回开始菜单。
- **横屏**：手机竖着拿时，整个游戏自动旋转 90 度按横屏显示；点「开始比赛」时会尝试进入全屏并锁定横屏（部分浏览器不支持）。

## 5. 声音

全部用 Web Audio 实时合成，没有音频文件。浏览器规定要先点一下屏幕才能出声。

- **菜单音乐**：轻快的马林巴、尤克里里风格，约每分钟 128 拍。
- **比赛音乐**：D 大调夏日流行风格，每分钟 150 拍，有底鼓、军鼓、踩镲、八度贝斯、铜管和弦重音、琶音和渐强；跑完 80% 赛程后提速到 162 拍。
- **环境声**：持续的河水声，进入急流段更响。
- **音效**：划桨、开罐、技能就绪、撞礁石、扔鳄龟、被吓、水枪上膛和喷水、翻船、跳跃、落水、倒计时、冲线等。电脑对手的音效按距离变小，并区分左右声道。
- 开始菜单里能分别开关音乐和音效，比赛中右上角可以一键静音。设置保存在 localStorage（`river-tube-sound-v1`）。

## 6. 代码说明（river-kayak/index.html）

整个游戏在一个文件里，按顺序分为：

1. **CSS**：界面、按键、加载页、结果页、横屏压缩布局（`body.compact`）和旋转（`body.rot`）。
2. **HTML**：加载页、HUD、触屏按键、开始菜单、头像编辑器、结果页。
3. **加载控制脚本**：显示进度条，依次加载 Three.js（cdnjs，失败改用 jsDelivr）、等字体加载完，再调用 `window.__bootGame()`，第一帧渲染后淡出。
4. **游戏脚本 `__bootGame`**：
   - **河道**：用固定随机种子生成 64 个控制点，连成 Catmull-Rom 曲线（总长约 2400 米）。选手位置用「沿河距离 `u` + 横向偏移 `x`」表示，物理计算更简单。
   - **场景**：水面、急流泡沫、河岸地形、树林、远山、礁石、罐子、加速带、起点和终点拱门。
   - **选手**：漂流圈模型、贴纸头像（Sprite）、划桨动画。
   - **物理**：`physics()` 处理速度、转向、水流、河岸和礁石碰撞、吃罐子、跳跃、脱困；`boatCollisions()` 处理选手互撞。
   - **AI**：`aiControl()` 负责选线、避礁石、追罐子、放技能。
   - **技能**：`castSkill()` / `updateSkills()`，水枪动画在 `animGun()`。
   - **镜头**：`updateCamera()`，包括菜单环绕、追尾视角、水枪特写和慢动作。
   - **音频**：`AU` 对象、乐器 `I`、编曲 `playStep()`、音效表 `SFX`。

### 常用可调参数

| 参数 | 位置 / 名称 | 当前值 |
|---|---|---|
| 最高速度 / 加速度 / 倒划力度 / 加速额外速度 | `MAXV, ACC, BRAKE, BOOSTV` | 22 / 15 / 20 / 14 |
| 蓄力时间 / 滞空 / 跳高 / 冷却 / 水花半径 | `JUMP_CHARGE, JUMP_T, JUMP_H, JUMP_CD, SPLASH_R` | 0.8 秒 / 1 秒 / 4.6 / 1 秒 / 7 米 |
| 技能所需罐数 / 技能射程 | `SKILL_COST, SKILL_RANGE` | 3 / 70 米 |
| 开局缓冲时长 | `EASE_T` | 10 秒 |
| 礁石最小间距（礁石之间 / 礁石到岸） | `ROCK_GAP, ROCK_BANK_GAP` | 4.8 / 5.2 米 |
| 河道形状 | `mulberry32(20261120)` 的种子 | 改种子会生成另一条河 |

## 7. 已知限制

- 只有单人对电脑，没有联机对战。
- 电脑对手不会蓄力跳跃。
- 照片头像不会自动识别人脸，合照需要手动拖到脸上。
- iPhone 侧面的静音开关打开时，旧版 iOS 可能没有声音。
- 需要联网才能加载 3D 引擎和字体。
- 水枪特写的侧面镜头偶尔会被路过的选手挡住一部分画面。
